## 1. docs/ 整理
- **規則**：已 review 結案的 stage → `docs/history/`（**平鋪，不開子資料夾**，檔名已含 stage）；尚未結案的最新 stage 留 `docs/` 根，由 `active.md` 指向。
- 套用：S1/S2/S3 的 report + plan + html → `history/`；S1-2 master plan（原 `PLAN.md`）→ `history/plan_overview_s1-2.md`；**S4 暫留根**（待 review，可能返工）；`design_decisions.md` / `render_gotchas.md` / `future_ideas.md` / `active.md` / `weekly/` / `reference/` 留根。
- **`active.md` 永遠保留一個模板檔**（空或極簡也留）；只放指標，**不複製** stage 內容。

## 2. 資料生成與版控（上游決策）
- 場景改 **runtime 當場生成**，用**確定性生成器** `scene(i) = f(i, config)`（純函數，不靠時間/per-run RNG）。
- 兩條正交軸都要：
  - **確定性**：同 `i` + 同 `config` → 同場景，可復現。
  - **不重複**：每個梯度步餵新的 distinct 場景；以 **total steps** 思考，不是 epoch；eval/checkpoint 按 step 間隔。組合空間極大，基本用不完才需重複。
- **不存** 1000 張訓練 scenes（由 config 確定性重生）。只留 **~10 張報告配圖** + **凍結 test set**。
- **零件 patch 仍 Blender 預渲（不可妥協）**。多樣性天花板由 patch 池決定，runtime 生成救不了 patch 端問題（如 bend 信號弱、displace 退步）。
- **版控 = 零件 patch + 生成 config + 凍結 eval set**。

## 3. output/ 結構（git-ignored）
改為**以角色分類**：
```
output/
├── patches/        ← 零件預渲 patch（原 parts_stage2/ 正名）。版控對象
├── eval_set/       ← 凍結 test set（直接拿現有 test split 凍結，保跨 stage 數字可比）
├── samples/        ← ~10 張報告配圖場景
├── runs/<stage_tag>/   ← 訓練產出，內含 best.pt / history.json / train.log / snapshots/
└── archive/        ← scenes_black、S1 dataset、舊 stage model 等封存（S1 留著）
```
- `runs/` 子資料夾命名用**可讀的 `stage_tag`**（如 `s4_singlehead`、`s5_baseline`），不用 timestamp。
- **生成 config 放被 git 追蹤的 `configs/`**（不在 output/，因為它是版控核心）。
- 約束：**S4 待 review 的 artifact 只歸檔、不刪不動**；路徑寫死在 scripts → 物理遷移**和 src/ 重構一起做**。

## 4. src/ + schema + cli
```
src/
├── schema.py   ← 單一事實來源（最上游，先立）
├── render/     ← Blender 側：patch 預渲、背景生成（bpy）
├── data/       ← runtime 生成器 scene(i)、Dataset、eval_set 載入
├── models/     ← 架構（encoder-decoder + heads）
├── train/      ← 訓練迴圈（step-based + checkpoint cadence）
└── eval/       ← 指標、per-state IoU、confusion、報告圖
scripts/        ← 收薄或併入 cli（只 entry，不放邏輯）
configs/        ← tracked，放生成/訓練參數
```
- **`schema.py` = Python dataclass 單一事實來源**：每 head 的 `name / num_classes / level(pixel|instance) / source / loss`。model channel、dataloader、eval **全從此推導**。
- **護欄**：`level="instance"` 的 head **禁止**直接套 pixel-level loss（防 severity 那類「跑完才發現」的錯）。
- **`cli.py` 子指令（argparse）**。紀律：**knob 進 `configs/` 不進 CLI flag**（同時服務整齊 + 復現）、**邏輯只在 src/**。指令多到嫌煩再換 per-module 自我註冊（現在不做，避免 over-engineering）。
