# 課程規定摘要

> 課程：MEME552 深度學習理論與應用，NSYSU  
> 授課教師：曾偉智 (Wei-Chih Tseng)，wctseng@mail.nsysu.edu.tw

---

## 基本資訊

| 項目 | 內容 |
|------|------|
| 報告日期 | 2026/06/02（週二）或 06/09（週二）|
| 日期分配 | TA 在報名後隨機分配 |
| 組別人數 | 3 人 / 組 |
| 報名截止 | 2026/04/28 前向 TA 報名 |
| 報告語言 | **英文口頭報告** |
| 時間 | 報告 10–15 分鐘 + Q&A 3 分鐘 |

---

## 題目類別（三選一）

1. **Quality Control & Defect Detection**：Pass/Fail 判定、表面缺陷定位
2. **Predictive Maintenance**：設備健康度預測、故障預警
3. **Sorting & Grasping Guided Systems**：零件辨識計數、抓取位置偵測

---

## 繳交內容

單一 `.zip` 檔案，包含：
- 所有資料來源
- 原始碼（`.ipynb` 格式）
- 簡報投影片

---

## 報告內容需涵蓋

- 任務介紹與挑戰定義
- 資料來源與前處理流程
- 模型架構說明
- 展示成果與最終預測結果

---

## 評分標準（各 20%）

| 項目 | 說明 |
|------|------|
| Problem Value & Creativity | 問題本身的實際價值與創意程度 |
| Technical Challenge | 自製/開源資料集、單/多目標任務 |
| Architecture & Completeness | 模型複雜度、架構邏輯與 pipeline 完整性 |
| Prediction Results | 測試集準確率 |
| Oral Presentation | 英文口頭報告品質 |
